# Granja Madre — Producción y trazabilidad

Sistema web adaptable a celulares y computadoras, con interfaz en español, para registros de producción, inventario, procedimientos, equipo, lotes y etiquetas QR.

El código de trabajo está en `sistema/`. Consulte `sistema/LEIA-ME.md` y `sistema/SUPABASE-INTEGRACAO.md` para ejecución y estado de la integración.

## Estado del proyecto

- La versión publicada utiliza Cloudflare D1 y acceso con ChatGPT.
- La copia de trabajo contiene la preparación de Supabase y cuentas individuales. Su configuración remota y migración de datos siguen pendientes; subir este código a GitHub no activa esa integración ni publica el sitio.
- La marca está aplicada en las pantallas y etiquetas. Su procedencia está documentada en `sistema/public/GRANJA-MADRE-LOGO-FUENTE.txt`.

Repositorio: https://github.com/MaicoLeal/Granja-Madre

No guardar contraseñas, claves de servicio, archivos .env ni datos de pacientes o producción en el repositorio.
